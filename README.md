# 💰 Orçamento Pessoal

Aplicação web desenvolvida para cadastrar, consultar e gerenciar despesas pessoais de forma simples e organizada.

O projeto utiliza o **Local Storage** do navegador para armazenar os dados, permitindo que as despesas permaneçam salvas mesmo após fechar ou atualizar a página.

## 🚀 Funcionalidades

- Cadastro de despesas
- Validação dos campos do formulário
- Validação de datas
- Armazenamento das despesas no Local Storage
- Exibição das últimas despesas cadastradas
- Consulta de despesas por:
  - Ano
  - Mês
  - Dia
  - Tipo
  - Descrição
  - Valor
- Pesquisa parcial por descrição
- Exclusão de despesas com confirmação
- Ordenação das despesas mais recentes primeiro
- Formatação dos valores em Real (R$)
- Interface responsiva

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Font Awesome
- Local Storage

## 💻 Como executar

O projeto não necessita de instalação ou servidor.

Clone o repositório:

```bash
git clone https://github.com/Lazaro277/orcamento_pessoal.git
```

Depois, abra o arquivo `index.html` no navegador.
